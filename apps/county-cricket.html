County Championship · 2014 to date · Cricsheet ball-by-ball

County Cricket

Every first-class county season since 2014, reduced to scorecards: tables, leaders, careers and the figures behind them. Pick a season, or go straight to a county, a player or a match.

Under the bonnetHow it works

1. The data

Everything on this page is read from the county-cricket realm, which stores the County Championship as six record types: CountyTeam (18), CricketPlayer (1,080), CountyMatch (1,483), TeamInnings (5,220), BattingInnings (51,173) and BowlingInnings (29,542). They are seeded from the realm's reference/ files, which scripts/build_reference.py builds by reducing every delivery in Cricsheet's County Championship archive (cricsheet.org/downloads, ODC-By) to scorecard lines. Nothing is fetched at query time, so a figure here is exactly as fresh as the last rebuild: seasons 2014 to 2026, no 2020 (that year's Bob Willis Trophy is not held), and the current season as far as Cricsheet had recorded it when the realm was built. Cricsheet's archive is not complete for every season: 2022 onwards hold all 126 fixtures, but 2014 to 2019 hold between 111 and 135 of the 144 played, so a county's "played" column in those seasons counts the matches held, not the matches it played.

The conventions the figures follow: a batter's balls faced exclude wides; a bowler is credited with caught, bowled, lbw, stumped, hit wicket and caught-and-bowled, and is charged runs off the bat plus wides and no balls (never byes or leg byes); a maiden is a complete over by one bowler conceding none of those; retired hurt and retired not out are not dismissals; a batting average is runs divided by dismissals, a bowling average runs conceded divided by wickets, economy runs per six legal balls, a batter's strike rate runs per hundred balls and a bowler's balls per wicket.

2. The questions

The page never writes a query. Each panel invokes a named view through the app runtime (embabel.views.invoke) with the parameters shown; the Cypher below is each view's saved definition, copied from views/cricket.yml at build time by scripts/inject_how_it_works.py.

CountySeasons — Every County Championship season the realm holds (2014 to 2026, no 2020), newest first, with how many matches, teams and divisions (groups in 2021) each has, the date span, and how many matches were decided or drawn. The first call an app makes, to know what can be asked.

Parameters: no parameters

MATCH (m:CountyMatch)
RETURN m.season AS season, count(m) AS matches, count(DISTINCT m.team1) AS teams,
       count(DISTINCT m.stage) AS stages, min(m.startDate) AS firstMatch, max(m.endDate) AS lastMatch,
       sum(CASE WHEN m.result = 'won' THEN 1 ELSE 0 END) AS decided,
       sum(CASE WHEN m.result = 'draw' THEN 1 ELSE 0 END) AS drawn
ORDER BY season DESC
CountyTeams — The 18 first-class counties with their all-time County Championship record in the data (2014 onwards) - matches, wins, draws, losses - and the seasons they span.

Parameters: no parameters

MATCH (t:CountyTeam)
OPTIONAL MATCH (m:CountyMatch)-[:TEAM]->(t)
WITH t, count(m) AS played,
     sum(CASE WHEN m.winner = t.name THEN 1 ELSE 0 END) AS won,
     sum(CASE WHEN m.result = 'draw' THEN 1 ELSE 0 END) AS drawn,
     sum(CASE WHEN m.loser = t.name THEN 1 ELSE 0 END) AS lost
RETURN t.name AS team, t.firstSeason AS firstSeason, t.lastSeason AS lastSeason,
       played, won, drawn, lost
ORDER BY team
CountyTable — The County Championship table for one season and division (a group in 2021) as results - played, won, drawn, lost, tied, wins by an innings - ordered by wins then draws. NOT the official points table: no points, bonus points or deductions exist in this realm, so a question about points has no answer here and must not be approximated from wins.

Parameters: season: int = 2026, stage: int = 1

MATCH (m:CountyMatch {season: $season, stage: $stage})
UNWIND [m.team1, m.team2] AS team
WITH team, m
WITH team, count(m) AS played,
     sum(CASE WHEN m.winner = team THEN 1 ELSE 0 END) AS won,
     sum(CASE WHEN m.result = 'draw' THEN 1 ELSE 0 END) AS drawn,
     sum(CASE WHEN m.loser = team THEN 1 ELSE 0 END) AS lost,
     sum(CASE WHEN m.result = 'tie' THEN 1 ELSE 0 END) AS tied,
     sum(CASE WHEN m.winner = team AND m.byInnings THEN 1 ELSE 0 END) AS wonByInnings
RETURN team, played, won, drawn, lost, tied, wonByInnings
ORDER BY won DESC, drawn DESC, lost ASC, team
TeamSeasons — One county's County Championship record season by season - which division (or 2021 group) it was in and its played, won, drawn, lost - newest season first.

Parameters: team: string = 'Surrey'

MATCH (m:CountyMatch)
WHERE m.team1 = $team OR m.team2 = $team
WITH m.season AS season, m.stage AS stage, m.stageName AS stageName, count(m) AS played,
     sum(CASE WHEN m.winner = $team THEN 1 ELSE 0 END) AS won,
     sum(CASE WHEN m.result = 'draw' THEN 1 ELSE 0 END) AS drawn,
     sum(CASE WHEN m.loser = $team THEN 1 ELSE 0 END) AS lost,
     sum(CASE WHEN m.result = 'tie' THEN 1 ELSE 0 END) AS tied
RETURN season, stage, stageName, played, won, drawn, lost, tied
ORDER BY season DESC
TeamResults — One county's County Championship matches - opponent, venue, date, whether it won, lost, drew or tied, and the margin - newest first, optionally for one season. Each row carries the match id for the scorecard and a link to ESPNcricinfo.

Parameters: team: string = 'Surrey', season: int = 0, limit: int = 200

MATCH (m:CountyMatch)
WHERE (m.team1 = $team OR m.team2 = $team) AND ($season = 0 OR m.season = $season)
RETURN m.matchId AS matchId, m.season AS season, m.stageName AS stage, m.startDate AS date,
       m.venue AS venue, m.city AS city,
       CASE WHEN m.team1 = $team THEN m.team2 ELSE m.team1 END AS opponent,
       m.team1 = $team AS listedFirst,
       CASE WHEN m.winner = $team THEN 'won' WHEN m.loser = $team THEN 'lost'
            WHEN m.result = 'tie' THEN 'tied' ELSE 'drawn' END AS outcome,
       m.margin AS margin, m.winner AS winner, m.url AS url
ORDER BY date DESC
LIMIT $limit
HeadToHead — Every County Championship match between two counties since 2014, newest first, with the result and margin - for "how have Yorkshire done against Lancashire" questions. Tally the rows for the head-to-head record.

Parameters: teamA: string = 'Yorkshire', teamB: string = 'Lancashire'

MATCH (m:CountyMatch)
WHERE (m.team1 = $teamA AND m.team2 = $teamB) OR (m.team1 = $teamB AND m.team2 = $teamA)
RETURN m.matchId AS matchId, m.season AS season, m.stageName AS stage, m.startDate AS date,
       m.venue AS venue, m.city AS city, m.team1 AS team1, m.team2 AS team2,
       m.result AS result, m.winner AS winner, m.margin AS margin, m.url AS url
ORDER BY date DESC
LIMIT 200
SeasonBatting — The leading run-scorers of a County Championship season - matches, innings, not outs, runs, highest score, average, balls faced, strike rate, fours, sixes, hundreds and fifties - optionally within one division (2021 group) or one county, with a minimum innings. Answers "who scored the most runs in 2025", "best batting average for Surrey", "most hundreds in Division 2".

Parameters: season: int = 2026, stage: int = 0, team: string = '', minInnings: int = 1, limit: int = 25

MATCH (b:BattingInnings {season: $season})
WHERE ($stage = 0 OR b.stage = $stage) AND ($team = '' OR b.team = $team)
WITH b.playerId AS playerId, max(b.player) AS player, collect(DISTINCT b.team) AS teams,
     count(DISTINCT b.matchId) AS matches, count(b) AS innings,
     sum(CASE WHEN b.notOut THEN 1 ELSE 0 END) AS notOuts,
     sum(b.runs) AS runs, max(b.runs) AS highScore,
     max(CASE WHEN b.notOut THEN b.runs ELSE -1 END) AS highNotOut,
     sum(b.balls) AS balls, sum(b.fours) AS fours, sum(b.sixes) AS sixes,
     sum(CASE WHEN b.runs >= 100 THEN 1 ELSE 0 END) AS hundreds,
     sum(CASE WHEN b.runs >= 50 AND b.runs < 100 THEN 1 ELSE 0 END) AS fifties
WHERE innings >= $minInnings
RETURN playerId, player, teams, matches, innings, notOuts, runs, highScore,
       highNotOut = highScore AS highScoreNotOut,
       CASE WHEN innings - notOuts > 0 THEN round(100.0 * runs / (innings - notOuts)) / 100.0 ELSE null END AS average,
       balls,
       CASE WHEN balls > 0 THEN round(10000.0 * runs / balls) / 100.0 ELSE null END AS strikeRate,
       fours, sixes, hundreds, fifties
ORDER BY runs DESC, average DESC
LIMIT $limit
SeasonBowling — The leading wicket-takers of a County Championship season - matches, innings bowled, overs, maidens, runs conceded, wickets, best figures, average, economy, strike rate and five-wicket hauls - optionally within one division (2021 group) or one county, with a minimum wickets. Answers "who took the most wickets in 2024", "best bowling average for Essex", "most five-fors".

Parameters: season: int = 2026, stage: int = 0, team: string = '', minWickets: int = 1, limit: int = 25

MATCH (b:BowlingInnings {season: $season})
WHERE ($stage = 0 OR b.stage = $stage) AND ($team = '' OR b.team = $team)
WITH b.playerId AS playerId, max(b.player) AS player, collect(DISTINCT b.team) AS teams,
     count(DISTINCT b.matchId) AS matches, count(b) AS innings,
     sum(b.balls) AS balls, sum(b.maidens) AS maidens, sum(b.runs) AS runs, sum(b.wickets) AS wickets,
     sum(CASE WHEN b.wickets >= 5 THEN 1 ELSE 0 END) AS fiveFors,
     max(b.wickets * 1000 - b.runs) AS bestCode
WHERE wickets >= $minWickets
WITH playerId, player, teams, matches, innings, balls, maidens, runs, wickets, fiveFors, bestCode,
     toInteger(floor((bestCode + 999) / 1000.0)) AS bestWickets
RETURN playerId, player, teams, matches, innings, balls,
       toString(balls / 6) + '.' + toString(balls % 6) AS overs,
       maidens, runs, wickets, bestWickets, bestWickets * 1000 - bestCode AS bestRuns,
       CASE WHEN wickets > 0 THEN round(100.0 * runs / wickets) / 100.0 ELSE null END AS average,
       CASE WHEN balls > 0 THEN round(100.0 * runs * 6 / balls) / 100.0 ELSE null END AS economy,
       CASE WHEN wickets > 0 THEN round(10.0 * balls / wickets) / 10.0 ELSE null END AS strikeRate,
       fiveFors
ORDER BY wickets DESC, average ASC
LIMIT $limit

PlayerSearch — Find County Championship cricketers by part of a name (case-insensitive) - their Cricsheet id, the counties they have played for, first and last seasons and matches. Names are as printed in scorecards (JE Root), so search by surname.

Parameters: name: string = 'Root'

3. When it looks wrong

A table is missing a team, or a county has played fewer matches than it should
Each division's table is built from the matches that season carries; a county appears once it has played. Cricsheet's archive is incomplete for 2014 to 2019 (see section 1), and early in a season the newest fixtures may not yet be in it, so a "played" column can be short of the fixture list.
There is no points column
Deliberate. Championship points need batting and bowling bonus points (which depend on where the first 110 overs ended) and over-rate deductions the umpires apply; neither is in the ball-by-ball record, so a computed points column would be wrong often enough to mislead. The table ranks by wins then draws, which is not the official order.
A leaders list is empty
The season has no innings matching the filters: the division or county chosen did not play that season (2021 had three groups, not two divisions), or the minimum innings is above what anyone reached.
A player has two entries
Players are keyed by Cricsheet's registry id, not by name, so two entries are two people who share a printed name. Their county list and seasons tell them apart.
An average shows a dash
No dismissals (batting) or no wickets (bowling): the average is undefined, not zero.
A panel says it could not load
The view call failed or the realm is not installed; the message names which. A panel that is genuinely empty says "no" something, never a blank.
The figures differ from ESPNcricinfo
Each match links to its ESPNcricinfo page. Cricsheet transcribes from the same scorecards, and a handful of innings in the archive are marked with miscounted overs or absent players; the realm's tests reconcile every season total against the raw files, not against the website.

4. What made this possible

The whole statistical layer is nineteen saved queries over records the realm seeds itself. There is no backend to deploy for this app, no database to administer and no nightly aggregation job: a season's leading run-scorers are summed from fifty thousand innings rows inside the query that fetches them (see SeasonBatting above), the same rows that feed a player's career and a match's scorecard, so a number shown twice is computed once. The page asks the world by view name when it loads; the same views answer the appliance's natural-language questions, which the realm's tests/questions.yml battery checks against these figures.
